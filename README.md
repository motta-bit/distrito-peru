# Distrito Perú — Carta Digital Interactiva

Muestra de propuesta (LQS) para **Distrito Perú · Gastronomía Peruana** — Laureles, Medellín.

Página web inmersiva y carta digital interactiva: menú navegable por categorías, buscador,
armador de pedido con envío por WhatsApp, sección de Instagram, tema claro/oscuro y bilingüe ES/EN.

**Sitio:** `index.html` (autocontenido). Publicado con GitHub Pages.
